# 사용자 시나리오: Chat을 통한 전처리 템플릿 사용

## 시나리오 개요

- **사용자**: 마케팅팀 김사원 (데이터 분석 초보)
- **목표**: 광고 캠페인 데이터의 결측값, 이상치, 중복 데이터를 정리하여 분석 가능한 상태로 만들기
- **데이터**: `ad_campaign_2025.csv` (5,000행 x 12열)

---

## 시나리오 흐름

### 1단계: 데이터 업로드

1. 사용자가 `pages/1_chat.py` (AI Chat 페이지)에 접속
2. 파일 업로드 영역에 `ad_campaign_2025.csv`를 드래그 앤 드롭
3. 데이터 미리보기가 자동으로 표시됨

```
┌─────────────────────────────────────────────┐
│ 데이터 미리보기                                │
│                                             │
│ 캠페인명 | 광고비 | 클릭수 | 전환수 | 지역 | ... │
│ 봄세일  | 15200 | 3420  | 182   | 서울 | ... │
│ 여름행사 |       | 2810  | 95    | 부산 | ... │
│ 가을특가 | 8900  | 1540  |       | 대구 | ... │
│                                             │
│ 5,000행 x 12열                               │
└─────────────────────────────────────────────┘
```

### 2단계: AI Chat으로 데이터 상태 질문

**사용자 입력:**

> 이 데이터를 분석에 사용하고 싶은데, 데이터 상태가 어떤지 알려줘

**AI 응답:**

> 업로드하신 `ad_campaign_2025.csv` 데이터를 분석했습니다.
>
> **데이터 상태 요약:**
>
> - 전체 5,000행 x 12열
> - **결측값 발견**: 광고비(320건, 6.4%), 전환수(185건, 3.7%), 지역(42건, 0.8%)
> - **이상치 의심**: 광고비 컬럼에서 극단적으로 높은 값 27건 탐지
> - **중복 행**: 동일한 캠페인명+날짜 조합 53건 발견
> - **데이터 타입 문제**: '날짜' 컬럼이 문자열(object)로 인식됨
>
> 현재 상태로는 바로 분석하기 어렵습니다. **전처리 템플릿**을 사용하여 데이터를 정리하는 것을 추천드립니다.

### 3단계: 전처리 방법에 대해 추가 질문

**사용자 입력:**

> 결측값은 어떻게 처리하는 게 좋을까?

**AI 응답:**

> 컬럼별 특성에 따라 다른 전략을 추천드립니다:
>
>
> | 컬럼  | 결측 수        | 추천 처리 방식 | 이유                    |
> | --- | ----------- | -------- | --------------------- |
> | 광고비 | 320건 (6.4%) | 중앙값 대체   | 이상치가 있어 평균보다 중앙값이 안정적 |
> | 전환수 | 185건 (3.7%) | 중앙값 대체   | 수치형, 분포가 치우쳐 있음       |
> | 지역  | 42건 (0.8%)  | 최빈값 대체   | 범주형 데이터, 결측 비율 낮음     |
>
>
> 전처리 템플릿에서 이 설정을 한 번에 적용할 수 있습니다. 실행해볼까요?

### 4단계: 전처리 템플릿 추천 수락

**사용자 입력:**

> 응 전처리 템플릿 실행해줘

- AI가 데이터를 분석한 결과를 `PreprocessingRequest`로 가공
- `st.session_state["preprocessing_request"]`에 저장
- 하단의 **"🔧 전처리 실행"** 버튼이 강조 표시됨
- 사용자가 버튼 클릭 → `pages/3_preprocessing.py`로 자동 이동

### 5단계: 전처리 템플릿 페이지 도착

Chat에서 전달된 데이터와 AI 추천 설정이 자동으로 채워진 상태로 표시됨

```
┌─────────────────────────────────────────────┐
│ 🔧 전처리 템플릿                                                                        │
│ 데이터 정제 및 변환을 수행합니다                                                         │
├─────────────────────────────────────────────┤
│                                                                                          │
│ ① 입력 데이터                                                                           │
│ ad_campaign_2025.csv (5,000행 x 12열)                                                    │
│                                                                                          │                                              
│ ② AI 분석 요약                                                                          │
│ "결측값 3개 컬럼, 이상치 27건, 중복 53건,                                                │
│  날짜 타입 변환 필요"                                                                    │
│                                                                                          │
│ ③ 전처리 설정                                                                           │
│                                                                                          │
│ [결측값 처리]                                                                            │
│  광고비: [중앙값 대체 ▼]                                                                │
│  전환수: [중앙값 대체 ▼]                                                                │
│  지역:  [최빈값 대체 ▼]                                                                 │
│                                                                                          │
│ [이상치 처리]                                                                            │
│  방법: [IQR 1.5배 기준 제거 ▼]                                                          │
│  대상: [광고비 ☑] [클릭수 ☑] [전환수 ☑]                                                │
│                                                                                          │
│ [중복 처리]                                                                              │
│  기준 컬럼: [캠페인명 ☑] [날짜 ☑]                                                       │
│  처리: [첫 번째 행 유지 ▼]                                                              │
│                                                                                          │
│ [타입 변환]                                                                              │
│  날짜: object → datetime [적용 ☑]                                                      │
│                                                                                          │
│ ┌─────────────────────────────────────┐           │
│ │            [ 만들기 ]                                                    │           │
│ └─────────────────────────────────────┘           │
└─────────────────────────────────────────────┘
```

### 6단계: 설정 확인 및 "만들기" 실행

1. 사용자가 AI 추천 설정을 확인 (필요 시 드롭다운으로 변경 가능)
2. **"만들기"** 버튼 클릭
3. 전처리 파이프라인 실행

### 8단계: 후속 작업 선택

사용자는 전처리 완료 후 다음 중 하나를 선택:

- **CSV 다운로드**: 정제된 데이터를 로컬에 저장
- **기초 EDA로 이동**: 정제된 데이터로 바로 기초 EDA 실행
- **본격 EDA로 이동**: 더 심화된 분석 진행

## 데이터 흐름 요약

```
Chat 페이지 (1_chat.py)
  │
  │  사용자: 데이터 업로드 + "전처리해줘"
  │  AI: 데이터 분석 → 전처리 설정 추천
  │
  ▼
session_state에 저장
  │  - preprocessing_request (PreprocessingRequest)
  │  - uploaded_df (DataFrame)
  │
  ▼
전처리 페이지 (3_preprocessing.py)
  │
  │  AI 추천 설정 자동 반영 → 사용자 확인/수정 → "만들기"
  │
  ▼
전처리 실행 (modules/data_analyzer.py + templates/preprocessing.py)
  │
  │  결측값 처리 → 이상치 처리 → 중복 제거 → 타입 변환
  │
  ▼
결과 표시 + 후속 작업 선택
  │  - CSV 다운로드
  │  - 기초 EDA / 본격 EDA로 이동 (정제된 데이터 전달)
```
